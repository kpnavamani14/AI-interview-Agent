# 🤖 AI Interview Agent

An AI-powered interview practice application that simulates a real interview and evaluates the user's answers.

## 🚀 Features

* Generates interview questions
* Allows users to answer interview questions
* Evaluates interview performance
* Provides a final interview score
* Simple and user-friendly interface
* Built using Python Flask and HTML

## 🛠️ Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* AI/LLM prompting

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/kpnavamani14/AI-interview-Agent.git
cd AI-interview-Agent
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python app.py
```

### 4. Open in browser

```text
http://127.0.0.1:5000
```

## 🎯 Purpose

The main goal of this project is to help students and job seekers practice interviews and understand their interview performance through an AI-based evaluation system.
